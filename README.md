# 👕 VIRTZ

> Loja de moda premium com carrinho interativo, suporte multilíngue e assistente virtual com IA.

🌐 **Website:** https://www.pablogdev.com.br  
🚀 **Demo:** https://pablog-7.github.io/virtz-site-exemplo/

---

## 🎯 Sobre o Projeto

A **VIRTZ** é um UI Concept de uma loja de moda premium desenvolvida para compor meu portfólio de desenvolvimento front-end. O projeto apresenta uma experiência de compra completa com catálogo de produtos, carrinho interativo, modal de detalhes, assistente virtual com inteligência artificial e suporte a três idiomas (Português, Espanhol e Inglês).

Desenvolvido com HTML, CSS e JavaScript puro, este conceito demonstra a criação de uma experiência de e-commerce completa e moderna, com foco em usabilidade, design premium e interatividade avançada.

## ⚡ Funcionalidades

### 🛒 Loja

- Hero section com chamada para ação
- Catálogo de produtos em grid
- Badges (Novo, Destaque, Promoção)
- Hover com ações rápidas (carrinho e visualização)
- Carrinho lateral com persistência
- Modal de detalhes do produto

### 💬 Assistente Virtual com IA

- Chat inteligente com reconhecimento de contexto
- Identificação de nome e email do usuário
- Base de conhecimento sobre produtos, frete, pagamento, trocas
- Detecção de intenção e humor
- Respostas proativas com sugestões
- Indicador de digitação
- Design com identidade VIRTZ

### 🌍 Multilíngue

- Suporte a 3 idiomas: Português, Espanhol, Inglês
- Alternância via bandeiras no header e menu mobile
- Tradução de todos os textos da interface
- Atualização dinâmica sem recarregar a página

### 📱 Experiência Mobile

- Menu hamburger com links de navegação
- Flags de idioma dentro do menu mobile
- Carrinho responsivo em tela cheia
- Chat adaptado para dispositivos móveis
- Botão flutuante otimizado para telas pequenas

## 💼 Sobre este Case

Este projeto faz parte da coleção de **UI Concepts** desenvolvidos para meu portfólio. O objetivo é demonstrar minha abordagem na criação de experiências de e-commerce completas, com foco em usabilidade, design premium e funcionalidades avançadas como assistente virtual com IA e suporte multilíngue.

Caso deseje transformar este conceito em uma aplicação real, ele pode ser expandido com React, TypeScript, Next.js, backend, banco de dados, autenticação e integrações personalizadas.
